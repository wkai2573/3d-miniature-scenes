# 0001：招牌字與日文場景名稱不翻譯，og 與 meta description 維持繁中

## 狀態

採用

## 背景

介面文字支援繁中、英文、日文三種語系，訪客可在場景選單切換。需要決定哪些文字跟著語系，哪些不跟。

## 決策

只有介面文字跟著語系切換。以下三類維持不動：

- **招牌字**：畫在 3D 場景貼圖上的文字，一律維持日文。
- **日文場景名稱**：場景卡片、選單按鈕與轉場布幕上的場景名稱，三種語系都用日文原名。卡片與布幕上那行場景說明則依語系翻譯，扮演名稱的副標題。
- **og:title、og:description 與 meta description**：維持繁中。

## 理由

- 招牌字是日式街景真實感的一部分。英文訪客看到日文招牌是預期中的畫面，翻成英文反而讓街景失去味道。
- 招牌字畫在貼圖上，要跟著語系切換就得重畫貼圖，還要為每種語系維護字元清單，成本遠高於它帶來的價值。
- 場景名稱是這組作品的風格所在，翻譯後會失去原名的語感；名稱不譯，才需要把說明翻出來讓看不懂日文的人知道場景內容。
- og 與 meta description 由爬蟲讀取，爬蟲不執行 JS，沒辦法跟著語系變。內容固定，分享預覽也比較穩定。

## 捨棄的作法

- **招牌字跟著語系重畫**：貼圖重畫與字元清單維護成本高，且破壞街景真實感。
- **場景名稱翻譯**：失去日文原名的語感，三種語系的名稱還要各自維護。
- **og 與 meta description 依語系提供多份**：需要伺服端依語言回傳不同頁面，或為每種語系各做一份頁面，與目前純靜態部署不合。
