# 01：臨時特寫視角，並截取改善前的畫面

**要建置什麼：** 使用者按 `V` 在俯瞰、全身、上半身與臉、雙手幾種特寫之間輪流切換，再按一次回到俯瞰。特寫時鏡頭跟著少女，可以拖曳繞轉、滾輪縮放，WASD 與 Shift 照樣能操作她，方向以畫面為準。切回俯瞰時，相機回到切換前的狀態，俯瞰視角的行為與原本完全相同。輸入焦點在可以打字的元件上或場景選單開著時，`V` 不會切換。

這個視角是臨時的，給使用者近看判斷自然度用。撐傘少女功能的跟拍視角（那邊的票 06）完成後移除，或併進跟拍視角。

動手改動作之前，先在每種特寫下以固定角度截取改善前的畫面，涵蓋全身、臉、雙手，存起來供最後的前後對比。

## Comments

### 實作紀錄

- 新增臨時的特寫視角模組 `src/scenes/konbini/girl/closeup.js`，少女載入後才建立；少女每格更新完，特寫時鏡頭跟著她平移。少女更新出錯被藏起來時，先回到俯瞰，之後按 `V` 也不再切換。
- 按 `V` 依序切換俯瞰 → 全身 → 上半身與臉 → 雙手 → 俯瞰，畫面上方短暫顯示目前的視角。每種特寫有固定的構圖：鏡頭對準的高度、相對她面向的偏角、俯角與距離，角度記在 `screenshots/README.md`。
- 鏡頭只跟著她平移，繞轉的角度與距離不變，所以可以照常拖曳繞轉、滾輪縮放；方向鍵本來就依相機的水平朝向，特寫時方向自然以畫面為準。
- 特寫時不能右鍵平移，改成滾輪往游標指的地方拉近，指著一隻手滾動就能看清楚那隻手；鏡頭中心限制在構圖中心 0.6 公尺內，反覆縮放也不會飄離她。
- 近裁切面在特寫時從 0.5 公尺改成 0.05 公尺；縮放下限臉是 0.4、手是 0.5 公尺，再近時鏡頭轉到側面會鑽進頭髮、手的描邊會拉出尖刺。
- 渲染流程每格把相機中心限制在底座範圍內，少女的可走範圍與鏡頭對準的高度都在範圍裡，不會和跟隨衝突。
- 切換前把拖曳放開後的阻尼慣性一次轉完，記下的俯瞰與新的構圖不會被它帶歪。切回俯瞰時，相機位置、鏡頭中心、近裁切面與改過的操作控制設定全部還原。
- 少女輸入抽出「按鍵該不該被忽略」的判斷，`V` 和 WASD 共用：焦點在可以打字的元件上或場景選單開著時忽略，焦點在時間滑桿上照樣能切換。`V` 用實體按鍵位置判斷，不受輸入法影響。
- 改善前的截圖：`screenshots/before-1-full.jpg`、`before-2-face.jpg`、`before-3-hands.jpg`。拍攝腳本是 `screenshots/shoot.mjs`，重拍方式見同一個資料夾的 README。

### 瀏覽器實測

- 用 Playwright 驅動 Chromium，GPU 為 D3D11，約 57 fps。
- 選單開著、焦點在文字輸入框時按 `V` 都不切換；焦點在時間滑桿時會切換。
- 特寫時按住 W 走路、按住 Shift 跑步，鏡頭都跟著她，她一直在畫面中央附近；拖曳繞轉與滾輪縮放正常。
- 拖曳放開後立刻按 `V`：特寫的偏角、俯角、距離與設定完全一致；切回俯瞰後相機停在慣性轉完的位置，之後不再漂移，平移、縮放範圍、近裁切面都回到原本的值。
- 先把俯瞰轉到別的角度，再切完一輪回來，和切換前的截圖相比平均每個色版只差約 1/255，是雨絲與少女位置的差異。
- 臉從正面與側面拉到最近都沒有被近裁切面切掉。
- 主控台沒有錯誤；只有瀏覽器自動要求的 favicon.ico 回 404，以及原本就有的 D3D 著色器編譯警告。

### 決策

- 鏡頭跟著少女平移但不跟著她轉身。方向鍵依相機朝向，鏡頭若跟著她轉，按住 A 或 D 時她會一直繞圈。
- 用往游標縮放取代右鍵平移：平移會把鏡頭中心拖離少女，往游標縮放則能直接拉近一隻手。
- 這次沒有新增自動測試。規格指定少女行為是唯一的測試接縫，特寫視角只動相機，不經過少女行為，改以瀏覽器實測驗證。

### 已知限制

- 特寫的構圖以切換那一刻她的面向為準；之後她轉身，鏡頭不會跟著繞到她面前，要自己拖曳繞轉，或按 `V` 切一輪回來。
- 環境音的聽者跟著相機，特寫時聽到的是站在她身邊的聲音。
- README 的操作說明沒有加上 `V`，因為這個視角是臨時的。
