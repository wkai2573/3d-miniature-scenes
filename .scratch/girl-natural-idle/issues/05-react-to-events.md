# 05：對場景事件轉頭

**要建置什麼：** 場景裡發生事情時，少女有時會轉頭看一下：自動門開始打開或關上、招牌閃爍、巷口路燈閃爍、紅綠燈換燈。事件在她看得到的地方時，大約三分之一的機會把視線轉過去，看一下再回到原本的狀態；不會每次都看，事件在身後時不看。

場景裡會發生事情的模組，每格把事件放進一份共用清單，內容是種類與世界座標，少女每格讀一次，當成場景資訊傳給少女行為。自動門開關、招牌閃爍、巷口路燈閃爍原本就有音效事件的時間點；紅綠燈換燈要新增。沒有少女時沒有人讀這份清單，場景照常運作。

規格見同一個功能資料夾的 spec.md，特別是「場景事件」、「少女行為」的事件規則，以及「測試決策」。

## Comments

### 實作紀錄

- 新增共用的場景事件清單 `src/scenes/konbini/events.js`：場景模組呼叫 `happen(種類, x, y, z)` 把事件放進清單，少女每格 `takeEvents()` 讀走並清空，當成場景資訊 `world.events` 傳給少女行為。沒有人在聽時 `happen` 什麼都不做，清單不會長大；少女載入失敗或更新出錯被藏起來時會停止記錄。
- 事件來源：自動門開始打開與關上（`doorOpen`、`doorClose`，在門口）、正面與側面招牌閃爍（`signFlicker`）、巷口路燈閃爍（`lampFlicker`，只在路燈亮著時，和電流聲同一個條件）、紅綠燈換燈（`signal`，新增，在店前轉角的行人號誌，每 32 秒的週期換六次）。事件和音效各自發出，音效沒開時照樣會有事件。
- 少女行為：待機時，事件在看得到的範圍裡，約三分之一的機會把視線轉過去（`gaze.kind` 是 `event`）看 1.2 到 2.5 秒，再回到原本的挑選；正在看事情時不會被下一件事拉走；走路、跑步時不理會事件；事件在身後就不看。
- 瀏覽器實測：站在店前面向店面，70 秒內看過自動門、招牌與巷口路燈各一到兩次，主控台沒有錯誤。
- 測試新增 2 個：看得到的事件有時會看、不是每次都看（40 次事件看了 5 到 35 次之間）；身後的事件一次都不看。

### 已知限制

- 少女自己走近讓自動門打開時，門也會發出事件，她有機會轉頭去看自己開的門。
