# 07：夜晚店內不再自己發光

**要建置什麼：** 夜晚時店內的商品有明暗，看起來是被店內的燈照亮，不再像自己在發光；店內整體比現在稍暗一點，和外面的雨夜融合。天花板燈管與冷藏櫃背板照舊發亮，從店外看，便利商店依然是街角裡亮著的那一家。用跟拍視角走進店內時不會過曝泛白；白天的店內依然自然。

規格見 [spec.md](../spec.md) 的「夜晚店內的亮度」。使用者沒有提供原本問題的截圖，判斷依據是商品材質不受光照影響又帶自發光；交付時請使用者確認是否就是原本看到的問題。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** resolved

- [x] 店內商品改用會受光照影響的卡通材質，拿掉或大幅降低自發光；原本不受光照影響的商品材質一併替換
- [x] 天花板燈管與冷藏櫃背板維持發光
- [x] 店內的點光源強度略微調低；店內招牌、海報等自發光平面依截圖判斷是否一起降低
- [x] 不更動全場景的曝光、泛光、天色調色盤與店外燈光
- [x] 截圖：夜晚與白天，俯瞰視角從店外看店內，以及跟拍視角在店內，對照改之前
- [x] `bun test` 全部通過

## Comments

### 實作紀錄

- `storeInterior.js`：商品材質 `productMat` 拿掉 `emissive`，冷藏櫃裡的飲料原本是不受光照影響的 `MeshBasicMaterial`（`productLit`），改成同一個會受光的卡通材質。天花板燈管與冷藏櫃背板（`glow` 材質）沒有動。
- 店內三盞點光源：夜晚改成原本的 0.3 倍，白天維持原本的亮度。作法是用 `nightLight`，建立時給夜晚的強度，`dayK` 給 1 / 0.3（大於 1 的意思是白天比夜晚亮），天亮天暗之間跟著 `ENV.lamps` 平順過渡。為什麼要壓這麼多：夜晚的泛光門檻只有 0.92（白天是 1.8），店內原本的亮度整片超過門檻，貨架與少女都被洗成白色；只拿掉發光（不降燈）時畫面幾乎沒有改善，降到 0.4 倍還是偏白，0.3 倍貨架與商品才有明暗。沒有動全場景的曝光、泛光、天色調色盤與店外的燈光。
- 招牌、海報等：貨架吊牌、おすすめ／NEW 小牌、玻璃內側海報有 0.4 ~ 0.5 的自發光，面積小，截圖看起來和招牌一樣是店內的「亮面」，沒有一起降低；菜單燈箱、菸架燈箱、冰櫃面板、咖啡機招牌是 `glow`，也留著。若使用者覺得還是太亮，下一個要降的是這些。
- 夜晚從店外看：店依然是亮著的那一家（招牌、雨棚、燈管仍亮，暖色光從玻璃透出來），貨架與商品有明暗；跟拍視角走進店內不再整片泛白，少女身上也不再過曝。白天的店內與改之前幾乎一樣。
- `bun test` 75 個全過；這是材質與燈光，沒有新增自動測試。
- 截圖：`screenshots/07-night-before-after.jpg`（夜晚，左改之前、右改之後；上到下：從店外看、跟拍視角在店內兩個位置、俯瞰角度看整家店）、`07-day-before-after.jpg`（白天，同樣的構圖，再加上整個場景的俯瞰：夜晚與白天）。
- 待使用者確認：這張是不是就是你原本看到的問題（店內像自己在發光）。
