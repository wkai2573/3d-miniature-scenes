# 01：可走範圍改成多個矩形的聯集

**要建置什麼：** 預先重構，為之後開放馬路與側街鋪路。店面配置的可走範圍從單一矩形改成多個矩形的聯集，少女行為把聯集以外的地方一律當成擋住；原本「把可走範圍的四條邊當成四堵牆」的推擠方式，改成適用於任意多個矩形的作法，在矩形交接處不會卡住，也不會從電線桿與邊界之間太窄的縫擠過去。這張票只放原本的那一個矩形，少女能走的地方與走動的方式完全不變。

規格見 [spec.md](../spec.md) 的「走到馬路上」。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** resolved

- [x] 店面配置的可走範圍是矩形的清單，目前只有原本那一個矩形
- [x] 少女行為、跟拍視角與其他讀取可走範圍的地方都改讀新的形式，不再有讀單一矩形的程式
- [x] 新增測試：可走範圍由兩個相接的矩形組成時，少女能從一個矩形走進另一個，交接處不會卡住；走到聯集外的角落會被擋住（可用測試自己組的配置）
- [x] `bun test` 全部通過，既有測試不需要修改

## Comments

### 實作紀錄

- `layout.js`：`bounds` 改成 `walkable`（矩形清單，目前只有原本那一個）；新增 `outsideOf(walkable, margin)`，用所有矩形的邊界把平面切成格子，沒被蓋到的格子併成方框，當成一公尺厚的牆。
- `behavior.js`：`spaceOf` 改讀 `outsideOf` 的結果（同一份可走範圍只算一次，以 WeakMap 快取），不再有「四條邊」的程式。凹角與交接處也是實心的方框，所以不會卡住、也擠不過縫。
- 新增兩個測試（L 形場地）：從一個矩形走進另一個；走向聯集外的角落被擋住，貼著邊斜著走能滑過交接處。既有測試沒有修改，`bun test` 60 個全過。
- 跟拍相機的 `cameraBounds` 是另一份資料，不屬於可走範圍，留到票 02 放大。
