## Comments

### 備齊截圖（等使用者驗收）

- 截圖在 `screenshots/08/before` 與 `screenshots/08/after`，構圖、拍攝條件與重拍方式見 `screenshots/README.md`；拍攝腳本放在 `screenshots/shoot/`。
- 改之前走不到的畫面（大馬路對面、側街對面）只有 after。
- 側街對面沒有拍「對照」之外的角度：`side-far` 是從側面看她站在對面人行道。
- **還沒有使用者的回饋**：最後一項（使用者在瀏覽器裡實際操作確認、回饋記在這裡）等使用者做完再填；需要修改的項目開新票。
- 需要使用者特別確認的幾點：
  1. 夜晚店內是不是原本看到的「自己在發光」（票 07），以及現在的暗度；要更暗或更亮，改 `storeInterior.js` 的 `NIGHT`（現在 0.3）。
  2. 撐開透明傘時右臂的姿勢，為了讓手腕修正變小，上臂放得比較下、手肘彎得比較多（票 06），手的位置幾乎沒變。
  3. 手臂下垂的角度（上臂約 80°）是用截圖調的，網路上沒有查到 VRoid／Mixamo 的數值（票 05 的留言）。
  4. 從出場處一直往南走會停在ガードレール的西端，要走斑馬線才到得了對街邊緣（票 02）。

### 使用者回饋

- 撐傘的右臂、手臂下垂角度的查證、斑馬線：通過。
- 手臂與手指：手要更自然垂下（前臂從手肘往前斜）、手臂再張開一點點、指間縫隙更小並自然垂下 → [09](09-arms-fingers-relax.md)
- 腳：待機與走路停下後看起來內八，要外轉、站寬一點 → [10](10-feet-toe-out.md)
- 夜晚店內：少女的衣服、頭髮、皮膚在店內會發光（夜晚 23:00 下雨、跟拍視角在貨架旁），反光要減少到約 1/5；夜晚店內燈再暗一點 → [11](11-night-store-girl-glow.md)
- 店內的跟拍視角希望可以自由轉動 → [12](12-store-camera-free.md)
- 第二輪驗收 → [13](13-user-review-2.md)
