# 05：手臂自然下垂

**要建置什麼：** 少女待機時手臂自然下垂、貼近身體，不再從肩膀往外張開：上臂下放到約 80°、稍微往前，手落在大腿外側略前方，手肘微彎，掌心朝向大腿，手不穿進軀幹或大腿。走路時以這個下垂的姿勢為中心擺臂；收起透明傘拿在手上時，右臂也是同樣自然下垂。呼吸、重心與偶發動作帶來的手臂小動作照舊；跑步的樣子與撐開透明傘時的舉傘姿勢不變。

## Comments

### 參考資料

網路上查不到 VRoid 或 Mixamo 待機姿勢的上臂角度實際數值（Mixamo 沒有公開，VRM 規格的初始姿勢是 T 字站姿），搜尋只找到下面這些，數值最後以截圖調整：

- [H-Anim 會議紀錄](https://www.old.web3d.org/wiki/index.php/Jul_15th,_2015_at_5:00pm_PDT,_Agenda_and_Minutes)：標準的 A 字站姿是手臂離身體 45°，所以從 T 字放到 A 字是 45°，自然下垂要再往下放更多。
- [vrm.dev：VRM 的初始姿勢是 T 字站姿](https://vrm.dev/en/vrm/vrm_features/)：旋轉量都以 T 字為零。
- [neural4d：A 字與 T 字比較](https://blog.neural4d.com/?p=3575)、[irendering：放鬆站姿手臂放在身側、手肘微彎](https://irendering.net/generating-t-pose-models-in-3d-techniques-and-benefits/)：定性描述，沒有數字。
- 解剖學的中立位：放鬆站著時肩膀外展約 0 ~ 10°、手肘微彎、掌心朝向大腿（沒有找到可引用的網頁，是一般常識，不是查到的）。

### 實作紀錄

- 站姿（`pose.js` 的 `stance`）：上臂從 T 字放下 1.2 → 1.4 弧度（約 69° → 80°）；往前 0.1 弧度（約 6°）；手肘 0.3 → 0.15；前臂繞自己的軸轉 0.2 弧度（約 11°），掌心朝向大腿。T 字站姿掌心朝下，上臂放到垂直時掌心本來就朝向身體，所以只需要很小的扭轉。
- 走路沿用同一個站姿基準，擺臂疊在上面。跑步樣式自己補回原本的數值：張開 `out = ARM_DOWN − 1.08`、往前 `offset`、手肘 1.35、前臂轉 `−FOREARM_TURN`，疊上新站姿後合計和改之前一模一樣（上臂 z −1.08、手肘 1.5）；跑步樣式的「手肘往前擺時多彎」另外用不含 `offset` 的數值算，所以也一樣。截圖對照確認跑步的樣子沒變。
- 收起透明傘的右臂（`HOLD_CLOSED`）：上臂下放 1.2 → 1.4、前臂轉 0.2、手肘 1.0 → 0.6（拿著傘手肘略彎）；撐開時的舉傘姿勢沒動。
- 待機的呼吸、重心、偶發動作對手臂的疊加都是加在站姿上的小量，沒動。
- 截圖（`screenshots/`，左改之前、右改之後）：`05-arms-idle-before-after.jpg`（待機全身與雙手特寫，撐著傘）、`05-arms-hands-sides-before-after.jpg`（左手側面與背面、右手收起時）、`05-arms-walk-closed-before-after.jpg`（收起傘的待機、撐著傘走路、收起傘走路，側面）、`05-arms-run-before-after.jpg`（跑步）。各角度手貼在大腿外側，沒有看到穿進軀幹或大腿。
- `bun test` 75 個全過；姿勢是外觀層，沒有新增自動測試（規格指定以截圖驗收）。
