# 01：語系核心與場景選單的語言切換

**要建置什麼：** 第一次進站時依瀏覽器語言決定語系：`ja*` 顯示日文，`zh*` 顯示繁中，其他顯示英文。場景選單的面板最下方出現「語言」一列，有 `繁中`、`EN`、`日本語` 三顆按鈕。按下後場景選單本身的文字立刻換成新語系，包括標頭、快捷鍵說明、開關按鈕與 aria-label；`<html lang>` 也一起更新。頁面不重新載入，選單保持開啟，焦點留在剛按的按鈕上。選過的語系存在 localStorage，換到別的場景或下次再來都沿用。日文介面的介面文字改用日本字形的字型。

這張票是曳光彈：建立語系核心這支一般腳本，三頁都在轉場布幕腳本與 boot 腳本之前載入它，並建立字典、`t()`、`set()`、`lang:change` 事件與語系判斷的完整路徑。其他介面在後續票券掛上字典。場景卡片上的場景說明、時間季節與風格標籤留給 02，這張票先維持原樣。

做法依 [spec.md](../spec.md) 的「語系核心」「各介面模組」「頁面與樣式」。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [x] localStorage key 為 `scene-lang`；localStorage 不能用時退回瀏覽器語言判斷且不報錯
- [x] 三個場景頁都在轉場布幕腳本與 boot 腳本之前載入語系核心，載入後 `<html lang>` 立即是正確語系

- [x] 切換時場景選單只更新文字與 aria 屬性，不重建 DOM；選單保持開啟，焦點留在按下的按鈕
