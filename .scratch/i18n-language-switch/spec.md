# 語系切換：介面文字支援繁中、英文、日文，從場景選單切換

Status: ready-for-agent

## 問題陳述

三個場景的介面文字目前只有繁體中文：場景選單、場景卡片、時間天氣面板、聲音面板、跟拍視角與俯瞰視角的提示、載入與錯誤訊息，全部寫死在程式裡。`<html lang>` 也固定是 `zh-Hant`。

網站已經部署到 hub 公開展示，但看不懂中文的訪客不知道選單裡寫什麼、怎麼切換天氣和聲音，甚至看不懂「這個瀏覽器沒有開啟 WebGL」這類錯誤訊息，不知道自己為什麼看不到場景。日本訪客面對的是日式街景，介面卻是中文，也很突兀。

## 解決方案

介面文字支援三種**語系**：繁中、英文、日文。

- 第一次進站時看瀏覽器語言決定語系：`ja*` 顯示日文，`zh*` 顯示繁中，其他一律顯示英文。
- 場景選單的面板最下方新增一列「語言」，有三顆按鈕：`繁中`、`EN`、`日本語`，每顆都用該語言自己的寫法。按下後所有介面文字立刻換成新語系。3D 場景不重新載入，少女的位置、相機、天氣與時間都保留。
- 手動選過的語系存在 localStorage，三個場景頁共用；換頁或下次再來都沿用。
- 場景名稱是日文原名，例如「雨夜のことりマート」「秋夜の紅葉屋」，三種語系都保留不譯。場景卡片和轉場布幕上那行場景說明則依語系翻譯，讓看不懂日文的人也知道場景內容。
- 3D 場景裡畫在貼圖上的**招牌字**，例如便利商店招牌、販賣機、海報、「止まれ」、紅葉屋的「ゆ」，維持日文不翻。

## 實作決策

### 語系核心

- 新增一支**一般腳本**（不是 ES 模組）作為語系核心，三頁都在 `<head>` 或 `<body>` 中、早於轉場布幕腳本與 boot 腳本載入。轉場布幕與 boot 都是一般腳本，執行時機比模組早，所以語系核心必須是同步的一般腳本。
- 語系核心不能有 import 和 export，頂層存取 document、localStorage、navigator 前都要先確認它們存在，這樣 bun 測試可以直接載入它。
- 它掛在一個全域物件上，供一般腳本和模組共用。對外介面：
  - `lang`：目前語系，值為 `zh-Hant`、`en`、`ja` 之一，同時也是寫進 `<html lang>` 的值。
  - `t(key, vars?)`：取目前語系的字串，支援具名插值，例如「共 {n} 座」。
  - `set(lang)`：切換語系，寫入 localStorage、更新 `<html lang>` 與 `document.title`，然後在 window 發出 `lang:change` 事件。
  - `resolve(stored, navigatorLanguages)`：純函式，回傳應使用的語系。stored 是合法語系就用它；否則依序看瀏覽器語言清單，第一個以 `ja` 開頭的回傳 `ja`、以 `zh` 開頭的回傳 `zh-Hant`；都沒有就回傳 `en`。
  - `LANGS`：三種語系與各自的按鈕標籤（`繁中`、`EN`、`日本語`）。
  - 字典本體，供測試檢查。
- localStorage key 用 `scene-lang`，跟既有的 `scene-sound`、`scene-sound-volume` 命名一致。讀寫都包 try/catch，localStorage 不能用時退回 `resolve` 的瀏覽器判斷，而且不記憶。
- 腳本載入時立刻決定語系，並把 `<html lang>` 設好。這樣 boot 和轉場布幕執行時，就已經拿得到正確語系。

### 字典

- 三種語系的所有介面文字放在語系核心裡的同一份字典，用語意化的扁平 key 分組，例如 `menu.*`、`env.*`、`sound.*`、`boot.*`、`camera.*`、`scene.<id>.*`、`page.<id>.*`。
- 譯文由實作者撰寫，使用者審查 diff。英文用自然的英文 UI 用語；日文用自然的日文 UI 用語。日文的時段名稱與晴雨雪要讓日本人讀起來自然。
- 場景目錄的 `title` 維持單一日文字串，不進字典。`desc`、`when`、`style` 改成從字典取，key 用 `scene.<id>.desc` 等等。場景目錄對外的資料形狀改由呼叫端透過 `t()` 取得文字，目錄本身只保留不隨語系變動的欄位與字典 key 的規則。

### 各介面模組

- 場景選單、聲音面板、時間天氣面板、少女場景的相機提示，都改成從 `t()` 取字。各模組監聽 `lang:change`，**只更新文字與 aria 屬性**，不重建 DOM，也不重新綁定事件。這樣開關狀態、焦點、滑桿數值與正在播放的提示都會保留。
- 場景選單面板最下方新增「語言」一列：三顆按鈕組成的群組，目前語系的按鈕用 `aria-pressed="true"` 加上強調色標示。按鈕本身的標籤固定用各語言自己的寫法，不隨語系變動。按下後呼叫 `set()`，選單保持開啟，焦點留在該按鈕上。
- 按鈕外觀沿用場景選單現有的視覺語言，包括強調色 `--accent`、圓角與字重。在 `hover:none` 與窄螢幕下也要能點。
- 不加切換語言的快捷鍵。
- 轉場布幕在離開頁面時，從選單寫入的 sessionStorage 記錄讀取場景說明。這份記錄寫入時已經是目前語系的文字，換頁後語系沿用 localStorage，所以兩邊一致。布幕本身只需要改用 `t()` 取任何寫死的字（目前沒有）。
- boot 腳本的錯誤訊息與提示、`#note` 的載入文字改從 `t()` 取。`#note` 的初始文字由語系核心或 boot 在執行時依語系覆寫，HTML 裡保留繁中作為沒有 JS 時的後備。
- 分頁標題與畫布的 aria-label 由語系核心依頁面（`page.<id>.title`、`page.<id>.canvas`）設定。頁面 id 取自場景選單 `nav` 上既有的 `data-current`。
- 不翻的部分：`console.warn` 訊息。

### 頁面與樣式

- 三個 HTML 頁都多載入語系核心，位置在轉場布幕腳本之前。`<html lang>` 初始值維持 `zh-Hant`，由語系核心在執行時改寫。
- og:title、og:description 與 meta description 維持繁中，不動。爬蟲不執行 JS，也就沒辦法讓它們跟著語系變。
- `html[lang="ja"]` 底下把 `--ui-font` 改指向已經載入的 Zen Maru Gothic，讓日文介面的漢字用日本字形。英文與繁中維持現狀。
- 部署的複製清單已經涵蓋整個 `src`，語系核心放在 `src` 底下就不必改部署流程。

### 文件

- `GLOSSARY.md` 新增三個詞：
  - **語系**：介面顯示的語言，有繁中、英文、日文三種。
  - **介面文字**：疊在 3D 場景上的 HTML 介面裡的文字，會跟著語系切換。
  - **招牌字**：畫在 3D 場景貼圖上的文字，不隨語系切換。
- 新增一份 ADR，記錄「招牌字與日文場景名稱不翻譯、og 與 meta description 維持繁中」這個取捨與理由：
  - 招牌字是日式街景真實感的一部分。
  - 招牌字切換就要重畫貼圖、維護每種語系的字元清單，成本很高。
  - og 由爬蟲讀取，不執行 JS。

## 測試決策

好的測試只驗證外部行為，也就是語系怎麼判斷、字典是否完整、頁面是否正確載入，不驗證內部資料結構或 DOM 的重繪細節。

### 接縫一：語系核心（新增的唯一接縫）

bun 測試直接載入語系核心腳本，從它掛上的全域物件取得介面：

- **語系判斷**：
  - localStorage 有合法值時以它為準，不管瀏覽器語言。
  - 存值不合法或沒有存值時，看瀏覽器語言清單：`ja`、`ja-JP` → `ja`；`zh-TW`、`zh-CN`、`zh-Hant`、`zh` → `zh-Hant`；`en-US`、`fr`、`ko` → `en`。
  - 清單裡有多個語言時，依序取第一個符合 `ja` 或 `zh` 的。清單為空時回傳 `en`。
- **字典完整性**：三種語系的 key 集合完全相同，每個值都是非空字串。
- **插值**：具名插值能正確替換，例如「共 {n} 座」帶入 3。三種語系中同一個 key 的插值變數名稱一致。
- **場景目錄對應**：場景目錄裡每個場景的 `desc`、`when`、`style`、頁面標題與畫布說明，在字典中三種語系都有。

### 接縫二：頁面契約（沿用既有接縫）

在既有的場景目錄契約測試中補上：

- 每個場景頁都載入語系核心，而且順序在轉場布幕腳本與 boot 腳本之前。
- 部署的複製清單涵蓋語系核心檔案。

### 不寫自動測試的部分

專案沒有 DOM 測試環境，場景選單、聲音面板、時間天氣面板收到 `lang:change` 後的重繪，以及日文字型套用，由實際開啟三個頁面驗收：

- 三種語系各切一次，確認所有介面文字都換了，沒有殘留繁中。
- 在少女場景中邊操作邊切換，確認少女位置、相機、天氣與時間都保留。
- 清掉 localStorage，用不同的瀏覽器語言設定重新載入，確認預設語系正確。
- 手機寬度下語言按鈕能點、不溢出。

### 先例

- 場景目錄契約測試：用 bun 讀取場景目錄模組、HTML 原始碼與部署設定，驗證三者一致，不需要瀏覽器。
- 少女場景的行為與相機框取測試：用 bun 測純函式。

## 不在範圍內

- 招牌字，也就是 3D 場景貼圖上約 60 條日文字。
- og:title、og:description、meta description 的多語系。
- 用 URL 參數指定語系，例如 `?lang=en`。
- 切換語言的快捷鍵。
- `console.warn` 等開發者訊息。
- 三種以外的語系，以及簡體中文。
- 依語系調整日期或數字格式。時間面板的 `HH:MM` 三種語系都適用。

## 補充說明

- 場景說明在三種語系下都要翻，包括日文。這是場景卡片與轉場布幕上既有的那行說明，扮演日文場景名稱的副標題。
- 語系核心是一般腳本、靠全域物件提供介面。這是為了讓轉場布幕與 boot 這兩支一般腳本也能使用，不是隨意的選擇。之後如果這兩支改成模組，可以重新評估。
- 字典預估約 80 到 100 個 key。如果語系核心因此變得太長，可以把字典拆成同樣是一般腳本的獨立檔案，在語系核心之前載入。測試接縫不變。
