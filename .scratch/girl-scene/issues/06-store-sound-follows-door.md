# 06：店內聲音隨自動門開度

**要建置什麼：** 便利商店的店內濾波與音量改成每格連續追蹤自動門的開啟程度，並新增獨立的關門音。門開得越大，店內聲音越明亮越大聲，過渡更平順、與畫面同步。這是兩個便利商店場景共用的改良，原便利商店的店內聽感會依新行為變化。

**Blocked by（被誰阻擋）：** 02

**Status：** ready-for-agent

- [ ] 門全關與全開時，店內濾波與音量的終值與改動前相同
- [ ] 門開合過程中，聲音隨門片位置連續變化，沒有突兀的跳變
- [ ] 門關上時有獨立的關門音
- [ ] 原便利商店的自動門仍依原本的排程開關
- [ ] 請使用者在原便利商店聽過後確認新聽感可接受
- [ ] 沒有新增的主控台錯誤
