# 06：店內聲音隨自動門開度

**要建置什麼：** 便利商店的店內濾波與音量改成每格連續追蹤自動門的開啟程度，並新增獨立的關門音。門開得越大，店內聲音越明亮越大聲，過渡更平順、與畫面同步。這是兩個便利商店場景共用的改良，原便利商店的店內聽感會依新行為變化。

**Blocked by（被誰阻擋）：** 02

**Status：** ready-for-agent

- [x] 門全關與全開時，店內濾波與音量的終值與改動前相同
- [x] 門開合過程中，聲音隨門片位置連續變化，沒有突兀的跳變
- [x] 門關上時有獨立的關門音
- [x] 原便利商店的自動門仍依原本的排程開關
- [ ] 請使用者在原便利商店聽過後確認新聽感可接受
- [x] 沒有新增的主控台錯誤

## Comments

瀏覽器驗證時量測了濾波器與音量的目標值，沒有實際聽：門全關時是 380 Hz、0.04，全開時是 2200 Hz、0.09，與改動前相同；開合過程中數值連續變化。關門音是門關上時發出 doorClose 事件，由獨立的處理函式播放，只確認了事件路徑，沒有實際聽到。畫面渲染很慢（約 1.3 fps），所以是拉長時間觀察。第五項的聽感確認，待使用者聽過。
