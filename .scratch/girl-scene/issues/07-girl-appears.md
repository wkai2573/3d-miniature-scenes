# 07：少女出場與操作

**要建置什麼：** 少女出現在少女場景的露天，使用者可用 WASD 移動、按住 Shift 跑步、按 C 在俯瞰視角與跟拍視角之間切換。少女依所在區域自動撐開或收起透明傘，靠近自動門時門會打開，撐開的透明傘能擋住雨雪。少女的全部模組、事件與遮擋模組及其測試，搬進主專案獨立於便利商店建模模組的區域，換行符統一為 LF。VRM 模型連同授權說明放進倉庫的資產區，VRM 套件加入少女頁面的模組對照並維持原版本，部署流程涵蓋角色資產。模型或套件載入失敗時，場景照常顯示，只是沒有少女。少女場景使用沿用現況的硬編碼店面座標。

**Blocked by（被誰阻擋）：** 02、03、04

**Status：** ready-for-agent

- [x] 少女場景開場時，少女站在露天並有待機動作
- [ ] WASD 與 Shift 可移動與跑步，且不會觸發天氣或聲音切換
- [x] C 鍵切換俯瞰視角與跟拍視角，跟拍視角下相機會避牆
- [ ] 露天下雨時透明傘為撐開；走進雨棚下或店內時收起；回到露天再次撐開
- [ ] 靠近自動門時門打開，走進店內後門關上
- [ ] 撐開的透明傘下沒有雨雪穿過
- [ ] 夜晚在店內時不被泛光暈開，沿用 05 的亮度
- [x] 既有的少女行為測試與跟拍相機測試只因模組位置調整匯入路徑，並全部通過
- [x] 模擬模型載入失敗與套件載入失敗，場景仍正常顯示且主控台只有警告
- [x] 原便利商店與紅葉屋沒有出現少女，畫面與行為不受影響
- [x] 模型與套件的授權說明隨資產帶入

## Comments

少女模組放在 `src/scenes/girl/`，事件模組與遮擋模組也一起搬到這裡，便利商店的街景模組從這裡匯入。既有的少女行為測試與跟拍相機測試與實驗專案的內容逐行相同，共 86 項測試通過。
瀏覽器驗證：少女開場站在人行道，撐著透明傘；C 鍵切到跟拍視角，可拖曳旋轉到面對店面；以搬走模型檔、把套件網址改壞兩種方式模擬載入失敗，場景照常顯示，主控台只有警告；便利商店與紅葉屋不會請求模型。
未勾選的項目：移動與跑步、開傘收傘、自動門、傘下無雨雪、夜間店內不暈光，在瀏覽器裡沒有實際操作觀察，因為畫面渲染只有約 1.3 fps，按鍵移動來不及觀察，這些行為目前只由單元測試保證，請使用者手動驗收。
