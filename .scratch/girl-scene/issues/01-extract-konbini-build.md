# 01：抽出便利商店共用建立流程

**要建置什麼：** 預先重構。把便利商店場景從環境設定、各建模模組、靜態合併、天氣表面、主迴圈到就緒事件的建立流程，抽成一個共用函式，原便利商店的入口變成呼叫它的薄入口。共用函式原本接受「夜間店內亮度」選項（已在 05 移除，見底部備註）。完成後使用者看到的原便利商店，畫面、聲音、開場時間與天氣都和重構前完全一致。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [x] 原便利商店的入口只剩呼叫共用函式，建模順序與亂數序列和重構前一致
- [x] 共用函式接受夜間店內亮度選項，預設值等於現況，且此票尚未有任何呼叫者傳入其他值
- [x] 在瀏覽器開啟原便利商店，白天與夜晚、晴雨雪三種天氣下，畫面與重構前目視一致
- [x] 場景切換、轉場布幕、就緒事件與錯誤顯示的契約維持不變
- [x] 紅葉屋不受影響

## Comments

實作於 `src/scenes/konbini/scene.js`。瀏覽器驗證：晴、雪與雨在白天與夜晚都開過，畫面沒有異常、沒有主控台錯誤（沒有與重構前逐像素比對）。
後續變更：夜間店內亮度選項已在 05 移除（兩個場景統一用壓低版），所以共用函式不再接受該選項，第二項驗收已不適用。
