# 02：用 WASD 操作少女走路

**要建置什麼：** 玩家按 WASD 讓少女走路，方向以目前相機看出去的方向為準，按 W 一律是往畫面深處走。斜走和直走一樣快。她轉向時身體平滑轉過去，放開按鍵後平穩減速回到待機，待機與走路之間平滑過渡。走路時左右腿反相、手臂與對側腿同步、髖部有上下與左右的起伏、軀幹輕微反向扭轉，步幅和速度相符，看不到腳滑。

這張票同時建立「少女行為」這個唯一的測試接縫：一個不依賴 three.js 的純邏輯模組，對外只有建立初始狀態與每格更新兩個函式。畫面上的骨骼只讀它的輸出。

共用介面裡 `W` 切換天氣、`S` 開關聲音這兩個快捷鍵要拿掉，不另外綁新鍵。

規格見同一個功能資料夾的 spec.md，特別是「少女行為」、「移動」、「按鍵」與「測試決策」。

## Comments

### 實作紀錄

- 新增檔案都在 `src/scenes/konbini/girl/`：`behavior.js` 是少女行為，`layout.js` 是店面配置，`input.js` 是少女輸入，`behavior.test.js` 是測試。`bun test` 執行，共 4 項。
- 店面配置先放了出場位置，以及店內、雨棚下兩種區域；狀態的 `zone` 已經會回報露天、雨棚下、店內。可走範圍、障礙物、地面高度與自動門感應區留給票 03。
- 步幅固定，步伐相位依實際走過的距離推進；相位 0 與 0.5 是兩腳併攏的時刻。放開按鍵時，少女行為會選一個來得及的併攏點，沿著減速曲線剛好停在那裡，最多再走約 0.6 公尺、0.95 秒。
- 腿不參與待機與走路的混合，一律依步伐相位決定腳踝位置，再用兩節 IK 反推角度。著地的腳鎖在世界座標，轉向時不會跟著身體在地上打轉；偏離太遠或扭轉超過 0.6 弧度時才跟著拖過去。
- 瀏覽器實測腳掌滑動：直走 2 秒約 0.5 公分、起步 0.7 公分、停下 0.2 公分、走路中轉 90 度約 3 公分；鞋底最多陷進地面約 4 公釐。
- `W` 切換天氣、`S` 開關聲音已移除，`sound:toggle` 事件也一併拿掉。選單與聲音面板的按鍵提示已更新。

### 決策

- 「輸入焦點在面板元件上時不移動」只套用在可以打字的元件。時間與音量滑桿不吃字母鍵，焦點留在滑桿上時 WASD 照樣能走，否則拖完滑桿後要先點一下場景才能操作，和 `sound.js` 排除滑桿的做法一致。

### 已知限制

- 原地掉頭轉身時，著地的腳會被拖著轉，實測約 7 到 13 公分。要完全不滑需要轉身時另外踏步，之後若在跟拍視角下看得出來再處理。
- README 的操作說明仍寫著 `W`、`S`，依規格之後整份重寫時一起改。
